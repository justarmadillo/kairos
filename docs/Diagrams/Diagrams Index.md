# Diagrams

> **In plain words** — pictures of the same facts described elsewhere in words. They are written in **Mermaid**, a text format that Obsidian and GitHub render as a drawing; in a plain editor you read the arrows directly. Three kinds appear here: *flowcharts* (arrows mean "depends on" or "leads to"), *sequence diagrams* (vertical lines are participants, arrows are calls, read top to bottom), and one *ER diagram* (database tables and how they relate). How to read them: [[Learn/How To Read This Wiki|How To Read This Wiki]].
